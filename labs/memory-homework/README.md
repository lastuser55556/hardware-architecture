# Домашнее задание — Память

## 1. Сравнение HDD и SSD

| Параметр | HDD | SSD |
|---|---|---|
| Принцип работы | Магнитная запись на вращающихся пластинах, чтение головкой | Хранение данных в микросхемах флеш-памяти |
| Скорость чтения/записи (примерно) | 80–200 МБ/с | SATA: 450–550 МБ/с; NVMe: примерно 1500–7000+ МБ/с |
| Наличие движущихся частей | Есть: пластины и головки | Нет |
| Устойчивость к ударам | Низкая, особенно во время работы | Выше, поскольку нет механики |
| Уровень шума | Шум вращения и перемещения головок | Бесшумный |
| Цена за 1 ТБ | Обычно ниже | Обычно выше (зависит от модели и рынка) |
| Срок службы / ограничения | Механический износ, риск повреждения при ударах | Ограниченный ресурс перезаписи ячеек (TBW); зависит от типа памяти |
| Пример использования | Долговременные архивы, резервные копии, хранение больших файлов | Операционная система, программы, игры, рабочие проекты |

*Скорости ориентировочные: зависят от интерфейса, модели и условий тестирования.*

## 2. Определения терминов

1. **DDR (Double Data Rate)** — «удвоенная скорость передачи данных». Передача данных происходит на обоих фронтах тактового сигнала, что увеличивает эффективную скорость передачи по сравнению с передачей один раз за такт.
2. **DIMM (Dual In-line Memory Module)** — модуль оперативной памяти с отдельными электрическими контактами на двух сторонах печатной платы. Применяется, в частности, в настольных компьютерах.
3. **Ранг (rank)** — логическая группа микросхем памяти на модуле, которые контроллер выбирает совместно с помощью сигнала выбора кристалла (Chip Select). Один модуль может содержать один или несколько рангов.
4. **CAS Latency (CL)** — задержка в тактах от команды чтения столбца до появления соответствующих данных. Время в наносекундах зависит также от частоты памяти.
5. **Тайминги** — значения задержек различных операций оперативной памяти в тактах: например, CL (CAS), tRCD, tRP, tRAS. Меньшие тайминги не всегда означают меньшую задержку без учёта частоты.
6. **Двухканальный режим** — одновременная работа двух независимых каналов контроллера памяти. При подходящей конфигурации модулей увеличивает доступную пропускную способность ОЗУ, но не обязательно удваивает скорость программ.

## Вывод

HDD выгоден для хранения больших объёмов данных при ограниченном бюджете, SSD — для быстрой загрузки системы и приложений. Производительность ОЗУ зависит не только от объёма, но и от скорости передачи, таймингов и режима каналов.
