Самостоятельная работа по последнему слайду презентации «Биты и байты»: решить три логических выражения и провести эксперимент с побитовыми операциями в Python.

## Логические выражения

Обозначения: `¬` — НЕ, `∧` — И, `∨` — ИЛИ. В таблице `0` означает ложь, `1` — истину.

1. `¬(A ∧ B) ∨ ¬(A ∨ C)`.
   По законам де Моргана получаем `(¬A ∨ ¬B) ∨ (¬A ∧ ¬C)`. По закону поглощения результат: **`¬A ∨ ¬B`**, то есть `¬(A ∧ B)`. Значение от `C` не зависит.
2. `(A ∧ B) ∨ (¬B ∧ C)`.
   Это выбор между `A` и `C` по значению `B`: при `B=1` результат равен `A`, при `B=0` равен `C`. В дизъюнктивной форме выражение уже минимально. Равносильная конъюнктивная форма: **`(A ∨ ¬B) ∧ (B ∨ C)`**.
3. `(A ∧ B) ∨ ¬C`.
   При `C=0` всегда истина; при `C=1` истинно только тогда, когда одновременно `A=B=1`. Дизъюнктивная форма уже минимальна: **`¬C ∨ (A ∧ B)`**.

## Эксперимент в Python

Запуск: `python3 bit_experiment.py`. Файл [bit_experiment.py](bit_experiment.py) выводит таблицу истинности, проверяет упрощения для всех восьми комбинаций и показывает операции `&`, `|`, `^`, `~`, `<<`, `>>` с числами `13` (`00001101₂`) и `6` (`00000110₂`). Фактический вывод запуска сохранён в [output.txt](output.txt).

Для наглядности берётся маска `0xff`, то есть восемь младших битов. В Python `~13` равняется `-14`, так как целые числа не ограничены восемью битами; `(~13) & 0xff` даёт `242` (`11110010₂`). В дополнительном коде восемь бит `11110010₂` представляют `-14`.
