# Логические формулы и схемы

## Задание

Выполнить две части работы:

- из схемы записать формулу;
- из формулы построить схему.

## Формулы

Первая формула:

```text
F1 = (A ∧ ¬B) → (C ∨ ¬A)
```

Вторая формула:

```text
F2 = ¬(A ∧ (B → C)) ∨ D
```
